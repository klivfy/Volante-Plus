## Platform Architecture

### Chrome
- **Base**: Chromium (original)
- **Manifest**: MV3 (required v100+)
- **ID**: Auto-generated by Chrome Web Store
- **Storage**: chrome.storage.local
- **Background**: service_worker format
- **Update**: Auto via Chrome Web Store

### Edge
- **Base**: Chromium (derived from Chrome)
- **Manifest**: MV3 (required v100+) — **IDENTICAL to Chrome**
- **ID**: Auto-generated by Edge Add-ons
- **Storage**: chrome.storage.local (same as Chrome)
- **Background**: service_worker format (same as Chrome)
- **Update**: Auto via Edge Add-ons
- **Difference**: No browser_specific_settings needed

### Firefox
- **Base**: Gecko (Mozilla)
- **Manifest**: MV3 (required v115+) — **Different format**
- **ID**: UUID (must be specified in manifest)
- **Storage**: chrome.storage.local (compatibility layer)
- **Background**: scripts array (not service_worker)
- **Update**: Auto via Mozilla Add-ons
- **Difference**: Requires browser_specific_settings.gecko
