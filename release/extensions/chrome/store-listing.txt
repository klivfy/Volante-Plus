Volante+ - Gerador de Jogos de Loterias

SHORT DESCRIPTION (max 132 characters)
================================================================================
Gera jogos de loterias direto da barra de ferramentas, com análise de desempenho e sincronização de novos sorteios.

FULL DESCRIPTION (max 16,300 characters)
================================================================================
Volante+ é uma extensão de navegador para análise inteligente e geração de jogos de loterias brasileiras.

RECURSOS PRINCIPAIS:

✨ Geração de Jogos Inteligente
- Analisa o desempenho histórico de números em loteria
- Sugere combinações baseadas em backtesting estatístico
- Suporta: Mega-Sena e +Milionária
- Interface simplificada direto da barra de ferramentas

🔄 Sincronização em Tempo Real
- Monitora novos sorteios automaticamente
- Notifica quando novos resultados são disponibilizados
- Atualiza dados de desempenho em background sem interrupção

📊 Análise de Desempenho
- Visualiza padrões de números mais frequentes
- Calcula probabilidades baseadas em histórico
- Dados sincronizados com a aplicação web Volante+

🔐 Privado e Seguro
- Funciona completamente offline (com cache)
- Dados locais armazenados no navegador
- Sem rastreamento ou coleta de dados pessoais
- Código aberto e auditável

COMO USAR:

1. Instale a extensão a partir da Chrome Web Store
2. Clique no ícone Volante+ na barra de ferramentas
3. Selecione a loteria desejada (Mega-Sena ou +Milionária)
4. Visualize números com melhor desempenho
5. Gere lotes de jogos automaticamente
6. A extensão sincroniza dados em background a cada hora

COMPATIBILIDADE:

- Chrome: versão 100+
- Edge: versão 100+ (compatibilidade MV3)
- Funciona offline após primeira sincronização

PERMISSÕES SOLICITADAS:

- storage: Armazena dados de desempenho e preferências localmente
- alarms: Agendamento de sincronização periódica de dados
- Acesso a loteriascaixa-api.herokuapp.com: Busca dados oficiais de sorteios

PRIVACIDADE:

Volante+ não coleta nenhum dado pessoal. Todos os dados são armazenados
localmente no seu navegador. Nenhum rastreamento é feito. A extensão
respeita sua privacidade completamente.
