Volante+ - Gerador de Jogos de Loterias

SUMMARY (max 250 characters - what users see in search results)
================================================================================
Gera jogos de loterias com análise de desempenho histórico direto da barra de ferramentas. Sincronização automática de novos sorteios.

DETAILED DESCRIPTION (max 10,000 characters)
================================================================================
Volante+ é uma extensão Microsoft Edge para análise inteligente e geração de jogos de loterias brasileiras.

PRINCIPAIS RECURSOS:

✨ Geração de Jogos Inteligente
- Analisa o desempenho histórico de números em loterias
- Sugere combinações baseadas em backtesting estatístico
- Suporta: Mega-Sena e +Milionária
- Interface simplificada direto da barra de ferramentas
- Funciona completamente offline com dados cacheados

🔄 Sincronização Automática em Tempo Real
- Monitora novos sorteios automaticamente
- Notifica quando novos resultados são disponibilizados
- Atualiza dados de desempenho em background
- Executa sincronização a cada hora sem interrupção

📊 Análise de Desempenho
- Visualiza padrões de números mais frequentes
- Calcula probabilidades baseadas em histórico
- Dados sincronizados com a aplicação web Volante+
- Interface gráfica intuitiva com resultados visuais

🔐 Privado e Seguro
- Funciona completamente offline após primeira sincronização
- Dados locais armazenados no navegador Edge
- Sem rastreamento ou coleta de dados pessoais
- Sem cookies de terceiros
- Código aberto e auditável no GitHub

COMO USAR:

1. Instale a extensão a partir da Microsoft Edge Add-ons
2. Clique no ícone Volante+ na barra de ferramentas
3. Selecione a loteria desejada (Mega-Sena ou +Milionária)
4. Visualize números com melhor desempenho
5. Gere lotes de jogos automaticamente
6. A extensão sincroniza dados em background automaticamente

COMPATIBILIDADE:

- Microsoft Edge: versão 100+ (Manifest V3 compatível)
- Suporta Edge em Windows, macOS e Linux
- Offline-first: funciona sem internet após cache inicial
- Sincronização com Chrome: compatível com perfis sincronizados

PERMISSÕES SOLICITADAS:

- storage: Armazena dados de desempenho e preferências localmente no navegador
- alarms: Agendamento de sincronização periódica de dados (a cada 60 minutos)
- Acesso a loteriascaixa-api.herokuapp.com: Busca dados oficiais de sorteios

Por que essas permissões são necessárias:
- storage: Mantém histórico de números e análises para funcionar offline
- alarms: Permite sincronização automática de novos sorteios em background
- Host permission: Busca dados oficiais de loterias para análise

PRIVACIDADE E DADOS:

Volante+ não coleta nenhum dado pessoal. Todos os dados são:
- Armazenados localmente no seu navegador Edge
- Nunca sincronizados com servidores de terceiros
- Completamente sob seu controle

Nenhum rastreamento é realizado. A extensão respeita sua privacidade completamente.

EDGE-SPECIFIC ADAPTATIONS & POLICY NOTES
================================================================================

DIFFERENCES FROM CHROME:

1. MANIFEST COMPATIBILITY:
   - Edge uses same Manifest V3 format as Chrome
   - No browser_specific_settings required (unlike Firefox)
   - Service worker format identical to Chrome
   - All Chrome APIs work in Edge without modification

2. EDGE ADD-ONS STORE POLICIES:
   - Similar to Chrome Web Store but with some differences
   - Privacy requirements slightly stricter
   - Must comply with Microsoft Services Agreement
   - Different review timeline (typically 24-72 hours)

3. PRIVACY CONSIDERATIONS:
   - Edge has built-in privacy protections (InPrivate mode, Tracking Prevention)
   - Extension should be transparent about data collection
   - Local storage only (no cloud sync of extension data)
   - Users can trust that Edge enforces same security as Chrome

4. PERMISSIONS MODEL:
   - Same permission system as Chrome
   - Users see permission warnings on install
   - runtime.requestPermissions() supported for optional permissions

5. DISTRIBUTION:
   - Edge Store URL: https://microsoftedge.microsoft.com/addons
   - Account: Microsoft (MSA or AAD)
   - Cost: Free submission (no registration fee like Chrome Web Store)
   - Review: Automated + manual (24-72 hours typical)

6. ACCOUNT REQUIREMENTS:
   - Microsoft Account (Hotmail, Outlook, or AAD)
   - Publisher identity verification may be required
   - Organization name/Individual developer name
   - Contact email for support

7. SUPPORTED FEATURES:
   ✓ chrome.storage API (local storage)
   ✓ chrome.alarms API (background scheduling)
   ✓ chrome.runtime API (messaging and events)
   ✓ Offline functionality
   ✓ Auto-updates from Edge Add-ons
   ✓ User reviews and ratings
   ✓ Extension statistics and analytics

8. NOT SUPPORTED IN EDGE (vs Chrome):
   - chrome.webRequest (deprecated in MV3 everywhere)
   - Sync storage (not available)
   - WebGL/WebGPU in service workers
   - Some deprecated Chrome APIs

9. EDGE-SPECIFIC BENEFITS:
   - Shared profile with Microsoft Account
   - Collections and reading list integration
   - Built-in reward system (Microsoft Rewards)
   - Better privacy controls than Chrome
   - Performance on lower-end devices

10. TESTING & QUALITY ASSURANCE:
    - Test in Edge 100+ (current stable)
    - Test in both Windows and macOS versions
    - Verify offline functionality works
    - Check that badge and notifications display correctly
    - Ensure background sync timing works (1 hour intervals)

11. SUBMISSION CHECKLIST FOR EDGE STORE:
    ✓ Manifest V3 valid (same as Chrome)
    ✓ All icons present (16, 32, 48, 128)
    ✓ Privacy policy URL accessible
    ✓ Support/help URL available
    ✓ Store listing clear and accurate
    ✓ No external scripts or CDN dependencies
    ✓ No eval() or dynamic code execution
    ✓ HTTPS-only for external connections
    ✓ No deceptive practices
    ✓ Proper content rating

12. DEVELOPER ACCOUNT SETUP:

    Step 3: Click "Become a developer"
    Step 4: Accept Microsoft Services Agreement
